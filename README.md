Press B4 and I'll Fall for You: a one-line pickup line spoken by a vending machine to a passing human, for the make.fun "One Line, One Minute: The Vending Machine Pickup Line Contest". `main.ts` writes a single 97-character line to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only. A runtime guard refuses to write anything outside the sealed scorer's 1–200 character gate.

> You don't need exact change to get my attention — just press B4 and I'll fall for you. Literally.

## Run it

```sh
node main.ts
```
